# ethers-rpc-pool

[🇬🇧 English](README.md) | 🇷🇺 Русский

Отказоустойчивый пул адресов JSON-RPC на TypeScript для ethers v6 и Node.js.

## Локальная полная проверка качества

Для запуска полной проверки качества на хосте требуется только Docker. Соберите
образ с зафиксированными версиями инструментов и запустите канонический npm-script
`quality`:

```sh
docker build --tag ethers-rpc-pool-quality .
docker run --rm ethers-rpc-pool-quality
```

Перед установкой зафиксированных зависимостей через `npm ci` образ проверяет
точные версии Node.js и npm. Script `quality` служит единым источником истины для
сборки, проверки типов, линтинга, герметичных тестов, покрытия и smoke-теста
упакованного npm-пакета.
